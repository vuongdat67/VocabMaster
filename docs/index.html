🔄 Luồng học

LIST → FLASHCARD → MODE LOOP → REVIEW POOL
1
List tổng quan

Xem grid tất cả từ. Click "Bắt đầu học ngay"

2
Flashcard tự đánh giá

Từng từ → lật thẻ → "Đã nhớ" / "Chưa nhớ". Bắt buộc qua test

3
Vòng xáo trộn ngẫu nhiên

Engine chọn ngẫu nhiên 1 trong 7 modes + từ theo priority SRS

4
Interleaving

Sau 3 câu, inject từ mới để pha loãng trí nhớ ngắn hạn

5
Mastery → Review Pool

Đúng liên tiếp 3 lần → tạm vững, chuyển sang lịch ôn dài hạn

🧮 Thuật toán SRS

Priority = wrongCount × 100 + (100 - accuracy%) + random(20)
Kết quả Tốc độ Priority Δ
✅ Đúng Nhanh (<3s) -30
✅ Đúng Thường -10
✅ Đúng Chậm (>8s) +10
❌ Sai Nhanh +50
❌ Sai Chậm +30
❌ Gần đúng — +15

📦 Three Queues

newWords (chưa học) │ │ (interleave: mỗi 3 câu → inject 1 word) ▼ learningWords (active rotation, priority-based) │ │ (correctStreak ≥ 3 → mastered) ▼ reviewWords (tạm vững, không active)

🎲 Mode Selection

Mỗi lần từ xuất hiện, engine chọn mode với bias:

  • Lần đầu gặp → flashcard
  • Mode chưa thử → ưu tiên cao
  • audio_challenge + typing_challenge → bắt buộc thử ít nhất 1 lần
  • Mode từng sai → weight 0.3
  • Mode vừa làm → weight 0.2
